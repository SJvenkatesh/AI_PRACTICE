# Example F — LangChain + Langfuse callback

**Reference notes, not run here** (needs a Langfuse account + keys).

Instead of wrapping each function in `@observe` (Example E), pass Langfuse's
callback handler to any LangChain/LangGraph `invoke()`. It auto-traces every
step — model calls, tool calls, retrievals — with no per-call instrumentation.

```python
from langfuse.callback import CallbackHandler

langfuse_handler = CallbackHandler()  # reads LANGFUSE_* env vars

result = agent.invoke(
    {"messages": [("user", "Why did activation drop?")]},
    config={"callbacks": [langfuse_handler]},
)
# Every LangChain/LangGraph step is now a span in the Langfuse trace UI.
```

This is the lowest-effort way to add tracing to code you already have: the
agents in Topics 5–7 (`create_react_agent`, the orchestration graph) would each
gain a full trace just by adding `config={"callbacks": [langfuse_handler]}` to
their `invoke()` calls — no other changes.

**Decorator (Example E) vs callback (this file):**

| | `@observe` decorator | Callback handler |
|---|---|---|
| Effort | wrap each function | one arg on `invoke()` |
| Granularity | exactly what you decorate | every framework step, automatically |
| Best for | custom / non-LangChain code | existing LangChain/LangGraph pipelines |

You can combine both — the callback traces the framework steps, and `@observe`
adds spans around your own non-LangChain helpers.
