# Example E — Langfuse integration

**Reference notes, not run here** — Langfuse is a hosted observability SaaS; it
needs an account and `LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY`. The local
tracer in `1.TraceStructure..py` + `6.debug_trace.py` shows the same *concepts*
(traces, spans, JSONL) without an external service. Langfuse is the managed
version: a hosted UI, cost tracking, prompt versioning, and eval scores.

## Instrument with the `@observe` decorator

```python
# pip install langfuse
from langfuse import Langfuse
from langfuse.decorators import observe, langfuse_context

langfuse = Langfuse()  # reads LANGFUSE_PUBLIC_KEY / LANGFUSE_SECRET_KEY from env

@observe(name="wise-albert-pipeline")
def run_wise_albert_pipeline(question: str, persona: str) -> str:
    langfuse_context.update_current_trace(
        metadata={"persona": persona},
        tags=["weekly_digest"],
    )
    return orchestrate(question, persona)

@observe(name="get_kpi_tool")
def get_kpi_traced(metric_id: str) -> dict:
    result = get_kpi(metric_id)
    langfuse_context.update_current_observation(
        input={"metric_id": metric_id},
        output=result,
    )
    return result

@observe(name="narrative_llm", as_type="generation")
def narrate_traced(evidence: dict, question: str) -> str:
    response = client.chat.completions.create(...)
    langfuse_context.update_current_observation(
        model="gpt-4o-mini",
        usage={
            "input": response.usage.prompt_tokens,
            "output": response.usage.completion_tokens,
        },
    )
    return response.choices[0].message.content
```

Nesting the decorated functions builds the trace tree automatically: the
pipeline is the trace, and each decorated tool/LLM call becomes a child span.

## What Langfuse gives you

- **Trace UI** — visualise every agent step, its input/output, and timing
- **Cost tracking per trace** — from the `usage` you report on generations
- **Eval scores attached to traces** (see Example 8 / Topic 10 — Evals)
- **Prompt versioning** — compare quality across prompt revisions

## Gemini note

These projects use Gemini, not OpenAI. Langfuse works with any provider — either
wrap your Gemini calls in `@observe` functions as above (reporting `usage` from
the LangChain response's `usage_metadata`), or use the LangChain callback handler
in Example 6, which auto-traces LangChain/LangGraph runs with no per-call code.
