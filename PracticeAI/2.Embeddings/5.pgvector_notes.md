# Example F — pgvector (Postgres, common in production)

This example is **notes, not a runnable script** — it needs a running Postgres
with the `pgvector` extension, which isn't set up on this machine. The concept
and SQL are below so the lesson is captured; wire it up later when you have a
database.

## Idea

Many teams already run Postgres for app data. `pgvector` adds a `vector` column
type and similarity operators, so embeddings live **in the same database** as
everything else — one system to back up, secure, and operate.

## Conceptual SQL

```sql
-- One-time: enable the extension
CREATE EXTENSION IF NOT EXISTS vector;

-- A table of embedded chunks. The dimension MUST match your embedding model:
--   OpenAI text-embedding-3-small -> vector(1536)
--   Gemini gemini-embedding-001   -> vector(3072)   <- what these projects use
CREATE TABLE document_chunks (
    id        SERIAL PRIMARY KEY,
    content   TEXT,
    source_id TEXT,
    embedding vector(3072)
);

-- Nearest neighbours. `<=>` is cosine distance (smaller = more similar).
-- :query_embedding is the embedded query, passed as a parameter.
SELECT content, source_id
FROM document_chunks
ORDER BY embedding <=> :query_embedding
LIMIT 5;
```

Operators: `<=>` cosine distance, `<->` L2 distance, `<#>` negative inner
product. For speed at scale, add an approximate index (`ivfflat` or `hnsw`)
on the `embedding` column.

## Why teams pick it

One database for app data **and** vectors — simpler ops, transactional
consistency, and you can `JOIN`/`WHERE` against your normal columns alongside
the similarity search.

## Vector database landscape

| Tool      | Best for                          |
|-----------|-----------------------------------|
| Chroma    | Learning, prototypes, local dev   |
| Pinecone  | Managed cloud, scale, low ops     |
| Weaviate  | Hybrid search, metadata filters   |
| Qdrant    | Performance, filtering            |
| pgvector  | Already on Postgres               |
| Milvus    | Large-scale self-hosted           |

You don't need to master all of them. Learn the **concepts** plus **one** tool
deeply — Chroma (Example E, for local dev) or pgvector (this file, for
production on Postgres).

## To make this runnable later

1. `docker run -e POSTGRES_PASSWORD=pw -p 5432:5432 pgvector/pgvector:pg16`
2. `pip install psycopg[binary] pgvector` (or use `langchain-postgres`'s `PGVector`)
3. Embed with `GoogleGenerativeAIEmbeddings(model="models/gemini-embedding-001")`,
   `INSERT` the 3072-dim vectors, then run the `ORDER BY embedding <=> ...` query.
